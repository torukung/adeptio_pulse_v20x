The capture map

One payment journey, sixteen nodes, four zones. The heavy spine is the main payment hop; thinner legs branch for authentication, balance reads, a partner shortcut and settlement. Everything sits above one read-only boundary — below it, a six-lane collector rail reads outward from the bank’s own network. Nothing above the line is touched.

Lane legend

Six collection lanes carry every hop on this map. Color and letter always travel together — never color alone.

L1 Synthetic probes — seeded accounts & vantages
L2 Protocol polling — SNMPv3 / DB & broker APIs, read-only
L3 Log streams — one JSON log line per hop (the backbone)
L4 API pulls — read-only tokens, written rate limit
L5 File feeds — read-only SFTP, landing dir only
L6 Read-only SQL — replica only, DBA-approved query set
